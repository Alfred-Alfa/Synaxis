# Chat Notification Sound

This directory should contain the chat notification sound file.

## Required File:
- `chat-notification.mp3` - A subtle corporate notification sound

## Instructions:
Please add a professional, subtle notification sound file as `chat-notification.mp3` in this directory.

The sound should be:
- Short (< 1 second)
- Subtle and professional
- Pleasant to hear repeatedly
- Corporate-friendly

## Temporary Solution:
For testing purposes, you can use any MP3 file. The application will gracefully handle missing sound files.

## Production:
For production, consider using royalty-free sounds from:
- https://mixkit.co/free-sound-effects/notification/
- https://freesound.org/
- https://soundbible.com/
