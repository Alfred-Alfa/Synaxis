# Chat Icon

This directory should contain the chat icon for browser notifications.

## Required File:
- Copy or create `chat-icon.png` in the `/public` directory

The icon should be:
- 192x192 pixels (or larger)
- PNG format
- Represents chat/messaging
- Professional and clean design

## Temporary Solution:
The notification system will work even without this icon. The browser will show default notification icons.

## Production:
For production, create or download a proper chat icon that matches your HRMS branding.
